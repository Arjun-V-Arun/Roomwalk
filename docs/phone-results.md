# Phone Results

Measured on real phones with `?stats=1`, then "Copy numbers". Software-rendered benchmark numbers in the README are for comparing formats; these are the numbers to quote.

| | | | | | | | |

How to fill a row:

1. Open `/r/<room>/?stats=1` on the phone, on the network you want to measure.
2. Wait for the room, then look around for about 10 seconds.
3. Press "Copy numbers" and copy `firstViewMs`, `fps`, `p95FrameMs`, `tier`, `pixelRatio` and `lodSplatScale` into the table.
4. Repeat with `&format=sog` and `&format=rad` to compare the two formats on the same phone.
